# Share provider access while keeping users' work private

Kimeru supports both personal connections and administrator-managed shared connections. Users can execute decisions through shared connections without receiving the stored API keys, while saved playgrounds, uploaded inputs, and run history remain private to their owner. This allows organizations to supply provider access without making administrators automatic readers of everyone's work; administrative authority and access to private work are separate boundaries.

The first account is the administrator. Public registration then closes, and administrators create later accounts. The user accepted this admission model instead of ongoing public signup.
